게임

규칙과 상호작용을 코드로 구현하고, 사용자가 자연스럽게 몰입할 수 있는 경험을 설계합니다.

관심 영역

게임 로직UI/UX레벨 디자인멀티미디어

웹과의 연결

  • 계정과 플레이 기록을 저장하는 백엔드
  • 랭킹과 업적을 제공하는 REST API
  • WebSocket 기반 실시간 상호작용
  • 반응형 웹 게임 인터페이스

학습 로드맵

설계핵심 재미, 규칙, 피드백 구조를 작은 문서로 정리합니다.
구현상태 관리, 충돌, 입력 처리와 화면 전환을 실습합니다.
서비스계정, 저장, 랭킹을 Spring Boot 서버와 연결합니다.

만들고 싶은 것

짧게 즐길 수 있으면서 학습 성취가 기록되는 브라우저 기반 미니 게임을 제작하고 싶습니다.
